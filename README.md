# Dev Kumar — Systems, at market speed

Responsive portfolio for Dev Kumar, focused on low-latency C++, market data, trading infrastructure, and hardware/software systems.

## Publish

This is a static site. GitHub Actions deploys the repository root to GitHub Pages on every push to `main` and on manual workflow runs. Enable **Settings → Pages → Build and deployment → GitHub Actions** once for the repository.

## Local preview

Open `index.html` in a browser or serve this folder with any static file server. The page uses an animated local SVG illustration and a small JavaScript file for project cards and motion; there is no build step.
